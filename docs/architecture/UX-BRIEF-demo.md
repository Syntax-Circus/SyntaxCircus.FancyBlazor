# UX Brief: FancyBlazor Demo

The demo serves Blazor developers evaluating the package. Its single job is to
show a real visual result immediately, then expose exact Razor to reproduce it.

Use a restrained “optical instrument” direction: midnight ink, nacre highlights,
precise grid lines, and compact technical labels. The signature is a live Nacre
specimen behind the hero. Pair a characterful display serif with a clean system
sans-serif without external font requests.

The landing page composes all four effects. Dedicated pages show minimal and
realistic usage, parameters, reduced-motion behavior, fallback behavior, and
copyable source. Responsive layout, visible focus, and reduced motion are mandatory.
